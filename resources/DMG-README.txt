Redraft

INSTALL
Drag Redraft.app to Applications, then launch it from Applications.
Grant Accessibility if macOS asks.
On a new Mac, enter your own provider API key in setup. Keys are device-local
and are never included in this disk image.

USE
Select text in an editor and press Command-Shift-E.
Type what should change ("fix grammar", "make this warmer") and press Return.
Include "use web search" in your typed instruction to search online.
Search costs extra and sends context to the search provider. Avoid private
details. Sources are in History, not in the pasted text.
The rewrite replaces the selection and stays on the clipboard.
Use your editor's normal Command-Z to undo a paste.

SETTINGS
Open Settings from Redraft's menu bar icon.
Models holds the Local or Cloud choice, the Keychain-backed API key and the
model. New installs use Gemini 3.5 Flash Lite through OpenRouter. Upgrades
preserve saved model choices.
You need your own provider account/key; API usage is billed by the provider.

UPGRADING
1. Quit the old Redraft from its menu bar icon before replacing it.
2. Drag this Redraft.app into Applications and choose Replace.
3. Launch /Applications/Redraft.app, not a copy inside this disk image.
4. Eject the disk image. About Redraft should show the version on this disk image.

Do not keep an older copy running or launch multiple copies from Downloads,
mounted disk images, or other folders. This disk image does not automatically
quit or replace a running app.

Saved provider/model choices, prompts, history, and Keychain keys are retained.
To return to the tested model, choose Recommended in Settings > Models.
If an old setup points to an unconfigured provider, reselect your provider
and model in Settings. Installing an update does not supply missing API keys.
If the shortcut or text replacement does not work, check System Settings >
Privacy & Security > Accessibility. If necessary, remove
the stale Redraft entry, add the app from Applications, and relaunch it.

Retired action presets from old versions are exported to a recovery file
before removal; General can reveal it. If a selection cannot be verified or
output is incomplete, Redraft copies the result to the clipboard instead of
replacing the original and tells you to paste it.

Native Liquid Glass requires macOS 26 or later. Earlier supported macOS
versions use native material. Redraft supports macOS 13+ on Intel and
Apple Silicon.
